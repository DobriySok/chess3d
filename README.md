# ШАХМАТЫ 3D — мультиплеер без сервера

Полностью статический сайт (работает на GitHub Pages). Вся логика — клиентский JS.

**Режимы:**
- **Локальные комнаты** — открой сайт в двух окнах одного браузера: комнаты видны в лобби сразу, без кодов (BroadcastChannel)
- **Двое за одним экраном** (хотсит)
- **Игра по сети** — другое устройство в интернете: один создаёт комнату (код из 5 букв), второй вводит код. Прямое P2P-соединение через WebRTC (PeerJS — публичный бесплатный брокер, после установки связи трафик идёт напрямую)

**Правила — полные:** рокировки (в т.ч. для Chess960-расстановок ладей), взятие на проходе, превращение, мат/пат, 50 ходов, недостаток материала. Корректность доказана перфт-тестами (`test_perft.js`: perft(4) = 197 281 — совпадение с эталоном).

**Управление:** клик по фигуре — ходы (точки), клик по подсветке — сделать. Мышь — вращение камеры, колесо — зум. Доска всегда развёрнута к играющему.

Часы: пуля/блиц/рапид/без часов · сдача · реванш со сменой цвета.
